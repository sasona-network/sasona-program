# Sasona program

The Solana contract that holds the network's money.

It holds what buyers pay and what members stake, and it pays out only under its own rules. A coin is created only when a dollar is deposited. No key, including ours, can create one any other way.

> Not deployed yet. This is part 1 of the [roadmap](https://github.com/sasona-network/roadmap). The program address will be here once it is on devnet.

Devnet only. The coin has no value.
